# Morph Launcher — Issue Tracker & Community

Welcome to the official issue and feedback tracker for **Morph Launcher**! 

This repository is dedicated solely to tracking bugs and feature requests. Code for the application is maintained in a private repository.

## 💬 Join Our Community

Have questions, general feedback, or want to chat with other users and the developer?

👉 **[Join the Morph Launcher Discord Server](https://discord.gg/5YdE4aWAfr)**

> **Note:** GitHub Discussions are disabled on this repository. For general talk, support, or quick questions, please join our Discord community!

---

## 🐛 Reporting Bugs & Requesting Features

Before creating a new issue, please search existing issues to see if your bug or idea has already been reported.

* **Report a Bug:** [Open a Bug Report](../../issues/new?template=bug_report.md)
* **Suggest a Feature:** [Open an Issue](../../issues/new) using the standard issue form.

When submitting a bug report, please provide as much detail as possible (device model, OS version, steps to reproduce) to help us resolve it quickly.
